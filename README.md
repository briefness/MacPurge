# 清爽 Mac 原生 macOS 版

仅供个人使用的原生 macOS 桌面清理工具。

## Architecture

- `SwiftUI + AppKit`：原生窗口、导航、菜单、macOS 权限和系统集成。
- `rust-core`：尚未接入 Swift 主程序的实验目录，不参与当前应用的扫描或清理。
- 功能覆盖：开发者缓存、项目构建产物、AI 工具产物、系统日志/安装包、废纸篓、逐层空间分析、保护列表、项目产物按更新时间推荐和轻量维护。
- 界面启动时为空，只显示运行时从本机读取的路径、大小、权限、磁盘和内存数据。缺失或无法读取的数据会显示为不可用，不会用估算值代替。清理操作会先写入清理记录，再将选中的真实路径移入 macOS 废纸篓。

## 权限策略

- 默认先使用用户目录和用户主动选择的位置进行基础扫描。
- 深度扫描涉及系统范围目录时，界面会逐项显示覆盖状态，并在用户主动点击后引导到“系统设置 → 隐私与安全性 → 完全磁盘访问权限”。
- 拒绝授权不会阻塞基础扫描；未覆盖的位置不会被伪造为扫描结果。

## 数据真实性

- 启动时不预置扫描结果，所有分类、路径、大小和空间占用都在本机运行时读取。
- 规则只用于定位可能的缓存或构建产物；路径不存在、无权限或已被保护时不会出现在结果中。
- 未授权的系统目录会显示为“需要授权”，不会用估算值代替。
- 空间透镜中的“未分类已用空间”只表示磁盘已用总量减去已读取目录的剩余部分，不冒充某个具体文件夹。
- 清理操作会真实写入清理记录，并将选中的路径移入废纸篓；写入或移动失败时保留失败项目的勾选状态并显示系统错误，不会伪造成功。废纸篓中的项目可由用户恢复，清理后的结果可通过重新扫描复核。
- 单个目录读取失败、跨越其他磁盘、超过 20 万个条目或达到时间上限时会明确标记为“部分读取”，并禁止选择该项，避免以不完整容量执行清理。
- 废纸篓使用独立入口，默认不选择任何项目；只有用户逐项选择并明确确认后才会永久删除。该操作不可恢复，不会与普通清理混用。

## 性能边界

- 启动时只读取磁盘总量、内存和轻量系统指标，不递归扫描整个磁盘。
- 清理扫描和空间分析只在用户主动触发后执行；进入“空间透镜”不会自动分析启动磁盘。
- 清理扫描最多运行 45 秒，空间分析和废纸篓扫描最多运行 30 秒，单个目录测量最多运行 3–5 秒。
- 文件遍历使用后台低优先级任务，并提供停止操作；同一时间只允许一个扫描、清理、永久删除或优化任务运行。
- 默认不跨越 APFS 数据卷、外接磁盘或网络挂载点递归统计；需要分析外接卷时，应由用户主动选择对应目录。

## Run

```bash
swift run
```

可以在 `rust-core` 目录中使用 `cargo test` 独立检查 Rust 引擎。

空间透镜支持从启动磁盘或用户选择的任意文件夹开始，逐层查看真实直接子项，并在访达中定位。项目构建产物默认推荐超过设置天数未更新的项目，默认值为 7 天，可在“设置”中调整为 1–30 天。

如果本机安装了 `cleanmymac` CLI，优化页会调用其 `optimize ram` 和 `optimize purgeable` 子命令；命令不存在时不会显示虚构任务。

## 打包与本机签名

默认使用无需账号的临时签名：

```bash
./scripts/package-app.sh
```

如需让完全磁盘访问权限在反复构建后更稳定，可在“钥匙串访问”的“证书助理”中创建类型为“代码签名”的本机自签名证书，然后使用固定证书名打包：

```bash
SIGNING_IDENTITY="清爽 Mac 本机签名" ./scripts/package-app.sh
```

个人仅在自己的 Mac 使用时不需要 Apple Developer Program、Developer ID 或公证。
